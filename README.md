# STC Metro CDMX

This repository contains a set of HTML files and a directory of images for a website about the Mexico City Collective Transport System (STC Metro). The site provides information on the history of the metro, the Metro Museum, and specific details about Line 1 and Line 2.

### Files

* **`index.html`**: The main page of the website. It serves as an index and provides links to the different sections.
* **`historia.html`**: Contains information about the history of the STC Metro, including its initial proposals, financing, and inauguration.
* **`museo.html`**: Details the different exhibition halls of the Metro Museum, including their content and illustrations.
* **`linea1.html`**: Provides information about the Pantitlán station on Line 1, including the origin of its name and its current status.
* **`linea2.html`**: Describes the Tasqueña station on Line 2, covering its name's etymology, its connection to the Light Rail (Tren Ligero), and its present condition.
* **`imagenes/`**: This directory contains all the images and multimedia files used on the website.

### How to View the Site

To view the website, simply open the `index.html` file in your preferred web browser.
